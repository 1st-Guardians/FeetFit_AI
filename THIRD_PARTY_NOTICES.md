# Third-party code

`segment_anything/` contains the existing Meta Segment Anything implementation.
Its Apache-2.0 license is retained in `SEGMENT_ANYTHING_LICENSE.txt`.

`vendor/aruco/aruco_foot_measure/` contains the ArUco detector and lens runtime used by this project.
It is bundled so an external source checkout is unnecessary.

PyTorch, torchvision, Ultralytics, Transformers and the other installed packages retain their respective licenses.
